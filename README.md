# Линейная алгебра

Решения заданий из четырех PDF. Каждая задача находится в отдельном Python-файле.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

Запускайте скрипт из его папки. Например:

```bash
cd practice5
python task1_methods.py
```

Графики сохраняются в текущую папку. Для `task2_operations.py`, `task3_accuracy.py` и `task4_graphs.py` файлы `task1_methods.py` и `task2_operations.py` должны находиться рядом, как в архиве.

## Структура

- `practice2`: определитель 3x3, матрица Гильберта, линейная регрессия.
- `practice4`: ранг и обратная матрица, проверка обратной, обусловленность, псевдообращение, ошибки округления, проверка входных данных.
- `practice5`: методы Крамера и Гаусса, счетчики операций, точность и графики.
- `lu_lup`: LU/LUP-разложения, верификация, устойчивость и производительность.

В `practice5/task1_methods.py` для метода Крамера используется заранее заданный вектор решения, после чего правая часть вычисляется как `b = A @ x_true`.
